# Diccionario de datos — tablas asignadas

Significado de las columnas de `factura`, `detalle_factura`, `turno_caja` e `historial_caja`, según las migraciones de la Entrega 2.

## `factura`

| Columna | Tipo | Nulo | Default | Significado |
|---|---|---:|---|---|
| `id_factura` | integer | No | `GENERATED BY DEFAULT AS IDENTITY` | Identificador único de la factura. |
| `id_mesa` | integer | Sí | — | Mesa asociada a la venta. Puede ser nula para pedidos para llevar y ventas directas. |
| `id_usuario` | integer | No | — | Usuario responsable de emitir la factura. |
| `fecha_emision` | timestamp without time zone | No | `CURRENT_TIMESTAMP` | Fecha y hora de emisión. |
| `subtotal` | numeric | No | `0` | Suma de los subtotales de las líneas facturadas, antes de la propina. |
| `propina` | numeric | No | `0` | Propina registrada para la factura. |
| `total_pagar` | numeric | No | `0` | Importe total cobrado; debe ser igual a subtotal más propina. |
| `id_comanda` | integer | Sí | — | Comanda cobrada por esta factura. Es única cuando tiene valor; nula para una venta directa. |

## `detalle_factura`

| Columna | Tipo | Nulo | Default | Significado |
|---|---|---:|---|---|
| `id_detalle_factura` | integer | No | `GENERATED BY DEFAULT AS IDENTITY` | Identificador único de la línea de factura. |
| `id_factura` | integer | No | — | Factura a la que pertenece la línea. |
| `id_producto` | integer | No | — | Producto vendido. |
| `cantidad` | integer | No | — | Unidades vendidas; debe ser mayor que cero. |
| `precio_unitario` | numeric | No | — | Precio aplicado al producto en esta venta; conserva el valor histórico. |
| `subtotal` | numeric | No | `0` | Importe de la línea; debe ser igual a cantidad por precio unitario. |

## `turno_caja`

| Columna | Tipo | Nulo | Default | Significado |
|---|---|---:|---|---|
| `id_turno_caja` | integer | No | `GENERATED BY DEFAULT AS IDENTITY` | Identificador único del turno. |
| `id_caja` | integer | No | — | Caja que se opera durante el turno. |
| `id_usuario_apertura` | integer | No | — | Usuario que abre el turno. |
| `id_usuario_cierre` | integer | Sí | — | Usuario que cierra el turno; permanece nulo mientras esté abierto. |
| `fecha_apertura` | timestamp without time zone | No | `CURRENT_TIMESTAMP` | Fecha y hora de apertura. |
| `fecha_cierre` | timestamp without time zone | Sí | — | Fecha y hora de cierre; nula mientras el turno esté abierto. |
| `monto_inicial` | numeric | No | — | Efectivo inicial registrado al abrir la caja. |
| `monto_final` | numeric | Sí | — | Efectivo contado al cerrar el turno; nulo mientras esté abierto. |
| `estado` | character varying | No | `'Abierto'` | Estado del turno: `Abierto` o `Cerrado`. |

## `historial_caja`

| Columna | Tipo | Nulo | Default | Significado |
|---|---|---:|---|---|
| `id_historial_caja` | integer | No | `GENERATED BY DEFAULT AS IDENTITY` | Identificador único del movimiento registrado. |
| `id_turno_caja` | integer | No | — | Turno de caja al que pertenece el movimiento. |
| `id_usuario` | integer | No | — | Usuario que registra el movimiento. |
| `id_factura` | integer | Sí | — | Factura asociada, si el movimiento corresponde a una venta facturada. |
| `metodo_pago` | character varying | No | — | Medio de pago: `Efectivo`, `Tarjeta` o `Transferencia`. |
| `tipo_pago` | character varying | No | — | Tipo de movimiento: `Ingreso` o `Egreso`. |
| `monto` | numeric | No | — | Valor monetario del movimiento; debe ser cero o positivo. |
| `descripcion` | character varying | Sí | — | Descripción adicional del movimiento, cuando aplica. |
| `fecha_movimiento` | timestamp without time zone | No | `CURRENT_TIMESTAMP` | Fecha y hora en que se registra el movimiento. |
